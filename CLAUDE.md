# CLAUDE.md

- Think Before Coding: Do not assume; explicitly state assumptions, ask for clarification if confused, and surface tradeoffs before writing code. 
- Simplicity First: Write the minimum code required to solve the problem, avoiding speculative features, unnecessary abstractions, or overengineering. 
- Surgical Changes: Touch only what is necessary for the specific request, do not refactor unrelated code, and clean up only the mess you created. 
- Goal-Driven Execution: Define clear success criteria and use test-first verification loops rather than vague implementation instructions.
- Never add `Co-Authored-By: Claude ...` or any AI attribution trailer to commit messages.
- Do not add comments to code unless they are very useful (i.e. the logic is non-obvious and cannot be made self-evident by better naming).
